雲端同步設定

同步檔會存在你自己的 Google 雲端硬碟，檔名「電話推廣名單-同步資料.json」。 資料不會經過任何第三方伺服器。每台裝置登入同一個 Google 帳號就會互相同步， 通話紀錄是合併的，不會互相覆蓋。

還沒有用戶端 ID？點這裡看設定步驟
  1. 到 Google Cloud 主控台 建一個專案（名稱隨意）。
  2. 左側「API 和服務 → 程式庫」，搜尋 Google Drive API，按啟用。
  3. 左側「OAuth 同意畫面」：User Type 選 外部，填應用程式名稱與你的信箱。
  4. 最容易漏掉的一步：在同一區找到「測試使用者」， 把你要用來登入的那個 Gmail 加進去。沒加的話登入會出現 「403 access_denied：只有測試人員可以存取」。
  5. 左側「憑證 → 建立憑證 → OAuth 用戶端 ID」，應用程式類型選 網頁應用程式。
  6. 「已授權的 JavaScript 來源」加入這個網站的網址，只到網域為止 （例如 https://你的帳號.github.io，後面的路徑不要加）。
  7. 建立後把「用戶端 ID」複製貼到上面的欄位。

同意畫面停在「測試」狀態就夠自己用，只是登入時會出現「這個應用程式未經驗證」的提醒，選「繼續」即可； 但每個要用的 Google 帳號都必須列在測試使用者裡。 不想維護名單的話，也可以在同意畫面按「發布應用程式」——這個網站只要 drive.file 權限（僅能存取自己建立的檔案），屬於不需送審的範圍。
